# 화면 녹화 줌 편집

<img src="./examples/zoom-preview.svg" alt="줌 편집 예시" width="720">

화면 녹화 영상에서 버튼·입력창·팝업처럼 꼭 필요한 곳만 확대하고, 화면을 바꾸는 진짜 클릭에만 빨간 라운드 박스를 넣어요.

## 설치 방법

1. 아래 링크를 복사해서 Claude/GPT 채팅창에 붙여넣고 "이 스킬 설치해줘"라고 말하세요.
   `https://github.com/ssaengcho01/ssaengcho/tree/main/zoom-in-screen`
2. 설치가 안 되면 [ZIP 내려받기](https://github.com/ssaengcho01/ssaengcho/archive/refs/heads/main.zip) 후 스킬(설정) 메뉴에 이 폴더를 업로드하세요.
3. 채팅에서 "이 화면 녹화 줌 편집해줘"처럼 말하면 스킬이 작동해요.

다시 공유하거나 활용할 때는 **@ssaengcho** 출처를 남겨 주세요. · [전체 스킬 보기](../)
