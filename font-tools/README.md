# 쌩초 폰트 도구 (웹)

👉 **바로 쓰기: https://ssaengcho01.github.io/ssaengcho/font-tools/**

설치 없이 크롬에서 여는 무료 폰트 도구 2종이에요.

- **내 폰트 다 모여** · 내 컴퓨터에 설치된 폰트를 한 화면에 크게 미리보기. 한글/영문 자동 분류, 내 문구로 미리보기, 클릭하면 폰트 이름 복사, 즐겨찾기.
- **이미지로 폰트 만들기** · AI로 그린 글자 견본 이미지를 한 글자씩 잘라 설치되는 `.otf` 폰트로. 워드·포토샵·캡컷 어디서든 써요.

만든 폰트를 설치하면 '내 폰트 다 모여'에서 바로 보여요.

## 쓰기 전에

- **PC의 크롬 또는 엣지**에서 열어 주세요. '내 폰트 다 모여'는 설치된 폰트를 읽는 기능이 이 두 브라우저에만 있어요. 처음 열면 "글꼴 접근 허용" 창이 뜨니 허용을 눌러 주세요.
- 이미지와 폰트는 내 컴퓨터 안에서만 처리돼요. 어디에도 올라가지 않아요.
- 이미지로 폰트 만들기는 영문·숫자·기호만 돼요(한글은 아직 안 돼요). 상용 폰트 견본을 떠서 만드는 건 개인 공부용으로만 쓰세요.

Claude에서 대화로 쓰는 버전은 [이미지로 폰트 만들기 스킬](../image-to-fonts)이에요.
