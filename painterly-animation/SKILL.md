# 회화 애니메이션 (Painterly Animation)

예시 작품: 쌩초의 자라섬 12초 광고(three.js 단일 HTML). 이전에 만든 index.html이 있으면 그 구조를 출발점으로 삼고, 없으면 아래 기법으로 새로 만든다.

## 원칙
- AI 이미지·영상 생성 도구를 쓰지 않는다. three.js(CDN import map three@0.160.0) 단일 index.html로 직접 그린다.
- 원작 디자인 복제 금지. 품질만 참고하고 캐릭터는 오리지널.
- 캐릭터는 귀엽고 친근하게. 확정된 옆모습이 있으면 정면을 새로 디자인하지 말고 같은 얼굴을 유지(대칭 확인).
- 사용자는 빠른 진행을 원함: 1차 결과를 빨리 보여주고 다듬는다.

## 그림 기법
- Canvas2D 시드 랜덤 붓터치: clump(3단 명암 덤불), paintShape(그라데이션·반점·아래 그림자·잉크 외곽선), cloud, forestRow, flowers, vine.
- 직교 카메라 + 깊이별 시차 레이어, 버텍스 셰이더 바람 흔들림.
- 물: 월드좌표 fbm 물결 + 햇빛 반짝임, 앞쪽 반투명 수면으로 잠긴 부분 표현, 수면 반사.
- 후처리: 쿠와하라(반경3) + 종이결 + 따뜻한 그레이드 + `#include <colorspace_fragment>`.
- 판타지 요소(떠 있는 섬, 폭포, 반짝이는 입자)로 세계관을 입힌다.

## 연출
- 컷 목록 SHOTS = [시작, 끝, 장면, x0,y0,x1,y1, 줌0,줌1, 롤0,롤1].
- 와이드·클로즈업·로우앵글·정면·브릿지컷(접사, 배경)을 섞는다. 옆모습만 반복 금지.
- 컷 전환에 하얀 플래시 금지. 그냥 컷.
- 눈 극단 클로즈업 금지(무섭다는 피드백).

## 작업 순서
1. 컷별 스틸을 뽑아 한 장 시안으로 먼저 보여주고 확인받는다(렌더 전 필수).
2. 렌더: playwright(크로미움, GPU가 없으면 swiftshader)로 `window.renderAt(t)` 프레임 캡처. 프레임 구간을 나눠 node 프로세스 4개로 병렬 렌더 → ffmpeg libx264.
3. 컷별 짧은 영상도 같이 잘라 준다.
4. 수정 요청 시 바뀐 컷의 프레임만 다시 렌더해 이어 붙인다.

## 소리
- CC0(출처 표기 불필요)만 사용. 예: GitHub의 `wyzowl/sfx-kit`, `biomathcode/coolhead-ambience` 같은 CC0 모음에서 고른다. 쓰기 전에 각 저장소의 라이선스를 한 번 더 확인한다.
- 앰비언스 + 사건 순간(변신, 첨벙 등)에 딱 맞는 효과음을 겹쳐 ffmpeg adelay/amix로 믹스.

## 자막·타이틀
- 흰색 고운바탕(@fontsource/gowun-batang), 제목은 디필레이아. HTML 오버레이를 playwright로 투명 PNG 프레임 렌더 → ffmpeg overlay.
- 자막은 짧은 한 줄(12자 안팎), 2초 이상 노출, 2~3줄이면 충분.
- 하단 비네팅은 항상 깔고, 엔딩 타이틀에서 서서히 사라지게.
- 엔딩 타이틀은 화면 중앙에 위 글귀 / 제목 / 아래 한 줄로 묶는다. 아래 줄은 담백한 정보.
- 실존 장소 광고면 실제 역사·특징을 검색해 출처와 함께 문구 후보를 먼저 제안한다.
