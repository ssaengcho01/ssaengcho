견본 이미지는 이렇게 만들면 잘 돼요
  • 흰 배경에 검은 글자, 글자끼리 붙지 않게 간격을 넉넉히.
  • 한 줄에 13자씩 A~M / N~Z / a~m / n~z / 0~9 순서로 그리면 글자 이름이 자동으로 붙어요.
  • 글자 높이가 300px 이상이면 확대해도 매끈해요. 작으면 울퉁불퉁해질 수 있어요.
  • 제목·설명 글씨는 빼 주세요. 섞여 있어도 다음 단계에서 지울 수 있어요.
  • 한글은 아직 지원하지 않아요(영문·숫자·기호만).

A clean type specimen sheet on a pure white background. Black letters only, no title, no labels. Row 1: ABCDEFGHIJKLM, Row 2: NOPQRSTUVWXYZ, Row 3: abcdefghijklm, Row 4: nopqrstuvwxyz, Row 5: 0123456789. Wide even spacing so no letters touch. Style: [원하는 스타일]

찾은 글자

칸을 클릭하면 선택돼요. 글자가 아닌 칸(장식·잡티)은 비워 두면 빠져요. 같은 글자가 두 번 있으면 앞의 것만 쓰여요.

한글 이름은 포토샵 등 일부 프로그램에서 목록에 이름이 안 보일 수 있어요. 영문 이름을 권장해요.
