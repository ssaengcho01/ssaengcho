# 예능 자막 하이라이트

영상 클립 여러 개 → 짧은 하이라이트 편집 → 예능 자막 → 최종본 + 모바일본.
사용자는 별도 프로그램을 열지 않는다. 수정은 **채팅**으로 받거나, 사용자가 **`자막_멘트.txt`의 멘트만** 고친 뒤 "다시 렌더"라고 하면 된다. 위치·크기·타이밍 같은 세부 조정은 채팅으로만 받는다.

필요한 것: ffmpeg, Python + Pillow. 스크립트는 이 스킬 폴더의 `scripts/`에 있다.

## 작업 순서

### 1. 소스 영상 파악
각 영상을 1초 간격 캡처 시트로 훑는다.
```
python <스킬>/scripts/sheet.py 영상.mp4 [출력.jpg] [간격초]
```
컷 경계는 `ffmpeg -i 영상 -vf "scdet=threshold=8,metadata=print:file=-" -an -f null -`로 정확히 잡는다.

### 2. 컷 목록 정하기 (기본 규칙)
- **첫 컷부터 흥미롭게.** 짧은 도입(인물 얼굴 등 1초 내외) 뒤 바로 가장 역동적이거나 눈길 끄는 장면으로.
- **같은 장면 반복 금지.** 같은 샷을 쪼개 여러 번 넣지 않는다.
- **인과관계가 있는 흐름.** 같은 활동·장소·주제끼리 묶고, 한 묶음 안에서는 시작 → 진행 → 다른 시점(리액션, 전경) 순서로. 비슷한 장면을 띄엄띄엄 섞지 않는다.
- **한 컷은 1~3초.** 비슷한 소재가 길게 이어지지 않게.
- **원본에 글자가 박힌 장면은 뺀다**(AI 생성 영상은 글자가 깨져 있기 쉬움). 사용자가 빼 달라는 장면이 있으면 비슷한 다른 컷까지 함께 뺀다. 그 밖에 위험하거나 부적절해 보이는 장면은 사용자에게 확인한다.
- 컷 끝을 장면 전환 시점에 딱 붙이면 다음 장면 한 프레임이 섞일 수 있으니 0.05초 여유를 둔다.
- 화면 페이드 인/아웃은 기본으로 넣지 않는다.

### 3. project.json 작성
`examples/예제_15초/project.json`을 복사해서 고친다. 결과물 폴더에 둔다.
- `sources`: 원본 영상 경로 목록. `cuts[].src`는 이 목록의 번호(0부터).
- `cuts`: `start`/`end`(원본 기준 초), `note`(메모).
- `audio`: `"original"`(컷마다 원본 소리, 이음새 자동 정리) 또는 `"none"`.
- `width`/`height`: 결과 화면 크기(기본 가로형 1280×720). 유튜브 쇼츠·릴스용 세로 영상이면 1080×1920으로.
- `subtitles`: 편집본 기준 시간. `id`는 1부터 고유 번호.

| style | 쓰임 | 위치 기본값 | 문법 |
|---|---|---|---|
| `pop` | 효과음·감탄사 (크림/주황 글자가 하나씩 튀어나옴) | 화면 가운데, `y`로 높이 | 짧게(2~5자) |
| `caption` | 하단 자막 (흰 글씨 + 보라 테두리) | 아래쪽 `y=0.86` | `{강조}`는 노란색 |
| `handwrite` | 엔딩 감성 손글씨 (은은한 빛 번짐) | `x`,`y` = 첫 줄 왼쪽 위 | `/`로 줄바꿈, 첫 줄 작게 둘째 줄 크게 |

`x`, `y`는 화면 비율(0~1).

**모든 자막은 가장자리에 붙지 않는다.** 스크립트가 가로 8%, 세로 9% 안전 여백을 자동으로 지켜서, 위치를 구석으로 줘도 안쪽으로 당겨진다(`margin_x`, `margin_y`로 조정 가능). 자막이 인물 얼굴이나 주요 피사체를 가리지 않는지도 꼭 본다.

**자막 문구 원칙:** 장면에 붙는 속마음·리액션 위주로 짧게. 효과음 자막은 한 영상에 1~2개만(많으면 정신없음). 손글씨는 마지막 장면에만.

### 4. 렌더
```
python <스킬>/scripts/make.py project.json
```
결과: `output` 이름의 최종본(원본 화질) + `_모바일.mp4`(480p) + `자막_멘트.txt`(처음 실행 때 생성).

### 5. 검수
`sheet.py`로 결과를 1초 간격 캡처해서 자막 겹침, 가장자리 붙음, 얼굴 가림, 다른 장면 프레임 섞임, 빼기로 한 장면이 없는지 확인한 뒤 전달한다.

### 6. 수정 받기
- **멘트만 바꾸고 싶은 사용자:** 결과 폴더의 `자막_멘트.txt`를 메모장으로 열어 `[ ]` 뒤 글자만 고치고 저장 → `make.py` 다시 실행. 멘트를 비우면 그 자막은 빠진다. 이 파일이 있으면 project.json의 `text`보다 우선한다.
- **그 밖의 수정(위치, 컷, 스타일, 타이밍):** 채팅으로 받아 project.json을 고친다. 자막을 새로 추가할 땐 새 `id`를 주고, 멘트 파일에도 같은 형식으로 한 줄 추가한다(`07 [3.2초 · 하단 자막] 멘트`).
- 사용자에게 전달할 때 멘트 파일 위치와 고치는 법을 한두 줄로 알려 준다.
